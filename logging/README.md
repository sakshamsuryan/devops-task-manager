Run `docker compose -f compose.yaml -f logging/compose.logging.yaml up -d` from the repository root. Filebeat tails Docker JSON log files, Logstash enriches error records and indexes into Elasticsearch, and Kibana provides search/visualization at http://localhost:5601. This single-node educational stack disables Elasticsearch authentication; keep it local and never expose it to an untrusted network. Filebeat requires Docker's default json-file logging driver and read access to `/var/lib/docker/containers`.
